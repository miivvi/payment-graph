# PaymentGraph — подбор ставки под заданную ПСК

## Задача

Клиент видит в договоре не годовую ставку, а ПСК — полную стоимость кредита в процентах годовых. ПСК учитывает всё: проценты, административную плату, плату за договор, и зависит от того, какими суммами и в какие даты клиент платит. Регулятор задаёт по ней потолок.

Ожидаемый результат в тестах — **таблица графика платежей целиком**, включая итоговую ПСК ([`tests/LimitsTest.php`](tests/LimitsTest.php)):

```php
yield [
  new PaymentGraphLimits(apr: 70, minInterestPercent: 9.9),
  <<<TEXT
          date | principal | interest | adm. fee | contract fee
    2025-10-02 |           |          |          |        50.00
    2025-11-10 |    162.07 |    12.76 |    11.70 |
    2025-12-10 |    167.71 |     9.82 |     9.00 |
    ...
    Monthly payment: 186.53
    Annual percent: 11.7812
    APR: 69.99
    TEXT
];
```
